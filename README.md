# homebrew-yogurt

Homebrew tap for [Yogurt](https://yogurt-ai.dev), a local-first meeting copilot for macOS.
The free source is [jarvisrchen/yogurt-open](https://github.com/jarvisrchen/yogurt-open).

```
brew install jarvisrchen/yogurt/yogurt
```

`Formula/yogurt.rb` is kept up to date automatically by the yogurt release workflow on every tagged release.
